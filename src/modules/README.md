# Módulos

Esta pasta reserva a organização modular do sistema Genect.

Cada módulo deve ser criado e detalhado apenas quando sua fase de implementação começar. Quando necessário, um módulo pode conter camadas como `domain`, `application`, `infrastructure` e `ui`, mas essas pastas não devem ser criadas por formalidade.

Antes de implementar regras de negócio, leia `docs/`.
